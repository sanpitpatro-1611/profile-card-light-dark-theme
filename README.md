## 🎨 About the Project

A modern personal profile card designed using **HTML, CSS and JavaScript**.

The project combines a minimal profile layout with creative visual elements, including a blurred background, glassmorphism design, animated glow effects and an interactive Light & Dark theme.

The objective was to create something simple, functional and visually appealing while learning the fundamentals of frontend development.

---

## ✨ Features

- 🌗 Interactive Light & Dark Mode
- 🖼️ Different profile images for each theme
- 🌫️ Blurred full-screen background
- 🪟 Glassmorphism profile card
- ✨ Animated background glow effects
- 🎭 Smooth card entrance animation
- 🪄 Hover effects on the profile card
- 🟢 Animated availability status
- 🔗 Interactive social media buttons
- 📱 Responsive design

## 🌓 Theme Preview

### Dark Mode
A darker visual atmosphere with a blurred background, transparent glass card and subtle glowing effects.

### Light Mode
A brighter theme with a different background image, lighter glass effect and updated text and component colors.
